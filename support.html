Assistance

Application Ce·Soir

Une question, un bug, une suggestion ? Écrivez-nous à support-cesoir@protonmail.com, on répond directement — Ce·Soir est développée par une seule personne, pas une équipe support.

Questions fréquentes

Comment supprimer mon compte ? Réglages → Compte → Supprimer mon compte. Cette action efface définitivement votre profil public, vos listes, vos favoris et vos données de compte.

Comment lier mon serveur Plex ? Réglages → Plex → Se connecter. La liaison est facultative et peut être retirée à tout moment depuis les réglages.

Puis-je utiliser Ce·Soir sans créer de compte ? Oui : la bibliothèque personnelle fonctionne sans compte. Un compte n'est nécessaire que pour le profil public et les fonctions sociales (abonnements, listes partagées).

Comment fonctionne le partage de bibliothèque à deux ? Réglages → Bibliothèque partagée → Inviter, via le mécanisme de partage iCloud d'Apple. Vous pouvez interrompre le partage à tout moment.

Une série ou un film manque dans les suggestions ? Les fiches proviennent de la base TMDB : un titre récent ou peu connu peut parfois manquer de données (affiche, disponibilités). Ce n'est pas un bug de l'application.
